# Photo credits

Every dish photograph in the demo comes from **Wikimedia Commons** and is used
under the licence shown below. Sourced by `scripts/find-photos.mjs`, then
checked by eye - a keyword-only pass returned a Buddha statue for Ayran and a
pork chop for a halal salad, so every image was reviewed before being kept.

**These are placeholders.** A real restaurant replaces them with photographs of
its own food by setting `photoUrl` on the dish; nothing else has to change.

To re-check that every URL still resolves:

```bash
node scripts/find-photos.mjs --verify
```
